# DSH 远控伴侣

把 [dsh-remote-control](https://github.com/ohmykreee/dsh-remote-control) 的远控页面放进一个独立的电脑窗口，在电脑上直接使用远控页面、麦克风和 VR 截图。

## 功能

- 输入远控地址后，页面占满窗口，自定义标题栏随时可回到设置。
- 应用菜单提供设置、关于本软件和退出；已连接时标题栏显示刷新。
- 选择系统麦克风并实时查看输入电平，远控页面使用所选麦克风。
- 让远控页面用当前 VR 画面代替剪贴板里的图片，可设置等待三秒后截图。
- 为未启用 HTTPS 的远控地址提供安全环境，让语音输入、剪贴板和麦克风等功能可以使用。

## 安装

1. 下载并解压压缩包到**可写目录**，不要放在 `C:\Program Files` 等只读位置。
2. 双击 `DSHRemoteCompanion.exe`。
3. 第一次启动会创建 `Data` 文件夹，设置与数据都保存在同级的 `Data` 中；移动程序时请连整个文件夹一起复制。
4. 使用 VR 截图时需要 SteamVR 正在运行，并先在头显中打开任意 VR 应用。

支持 Windows 10/11 x64。系统需要 Microsoft Edge WebView2 运行时；Windows 11 通常已自带。

## 使用

1. 在左侧填写 dsh-remote-control 显示的远控地址，例如 `http://192.168.1.20:38765/`。
2. 按需勾选「记住该地址」，点「前往」。
3. 页面载入后，点标题栏的「应用 → 设置」调整麦克风、VR 截图与安全环境。
4. 设置修改后会自动保存；需要应用到当前页面时，点标题栏的「刷新」。

### 麦克风

选中麦克风后下方会显示实时输入电平。远控页面申请麦克风时会自动使用这个设备，不需要再单独授权。

### VR 截图

开启「替换剪切板为 VR 截图」后，远控页面会把读取剪贴板图片改为读取当前 VR 画面。

- 需要 SteamVR 正在运行，并且头显中已经打开 VR 应用。
- 开启「延迟 3 秒后截图」后，等待期间每秒响一声提示，然后截图。
- 修改后点标题栏「刷新」使设置作用于当前远控页面。

### 安全环境

如果远控地址是 `http://`，浏览器可能不允许语音输入和读取剪贴板。开启「强制开启安全上下文」并刷新页面后，当前地址会获得需要的安全环境。使用 `https://` 时不需要开启。

## 已知限制

- 仅提供 Windows x64 版本。
- VR 截图只截取 SteamVR 当前显示的画面；没有运行中的 VR 画面时无法生成图片。
- 延迟提示音使用系统默认播放设备；静音时不会听到提示，但仍会按时截图。
- 应用菜单打开时远控页面会暂时隐藏，关闭菜单后恢复。
- 远控地址可能包含访问令牌，文件以明文保存在 `Data` 中，请勿把 `Data` 文件夹公开分享。
- 当前界面只有简体中文。

## 数据与重置

所有设置与数据在程序目录的 `Data` 文件夹。删除 `Data` 后重新启动会恢复出厂设置。
