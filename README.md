# DSH 远控伴侣

把 [dsh-remote-control](https://github.com/ohmykreee/dsh-remote-control) 的远控页面放进一个独立的电脑窗口，在电脑上直接使用远控页面、麦克风和 VR 截图。

## 功能

- 输入远控地址后，页面占满窗口，自定义标题栏随时可回到设置（Windows）；Linux 使用原生应用栏和下方工具栏。
- 「设置 → 安全上下文」提供「强制开启安全上下文」和默认开启的「自动开启安全上下文」。自动开启时，输入内网 HTTP 地址会自动启用安全上下文并保存。
- 应用菜单提供设置、关于本软件、置顶窗口/取消置顶窗口和退出；已连接时标题栏显示刷新。
- 选择系统麦克风并实时查看输入电平，远控页面使用所选麦克风。
- 让远控页面用当前 VR 画面代替剪贴板里的图片，可设置等待三秒后截图。
- 为未启用 HTTPS 的远控地址提供安全环境，让语音输入、剪贴板和麦克风等功能可以使用（Windows）。
- 「设置 → VRChat OSC 展示」可把时间与天气、音乐与进度、CPU/GPU 与内存、大肥鱼状态与余额，或一段自定义文字
  发送到 VRChat 聊天框；自定义文字支持占位符和预览。也可以开启快速问答推送，把选中的回答临时显示在聊天框。
  默认发送到 `127.0.0.1:9000`，地址和端口都可以修改。
- 可调整窗口透明度、设置全局老板键，并让窗口靠上、靠左或靠右自动收起。
- 标题栏会跟随远控页面的亮色或暗色主题切换。
- 连接页可在中文和英文之间切换；进入远控后自动跟随远控页面的语言，并保存供下次启动使用。

## 安装

### Windows

1. 下载并解压压缩包到**可写目录**，不要放在 `C:\Program Files` 等只读位置。
2. 双击 `DSHRemoteCompanion.exe`。
3. 第一次启动会创建 `Data` 文件夹，设置与数据都保存在同级的 `Data` 中；移动程序时请连整个文件夹一起复制。
4. 使用 VR 截图时需要 SteamVR 正在运行，并先在头显中打开任意 VR 应用。

支持 Windows 10/11 x64。系统需要 Microsoft Edge WebView2 运行时；Windows 11 通常已自带。

### Linux

1. 下载 `DSH-Remote-Companion-linux-x64.zip` 并解压到可写目录。
2. 给程序执行权限：`chmod +x DSHRemoteCompanion`。
3. 运行 `./DSHRemoteCompanion`。首次启动会在程序旁创建 `Data` 文件夹。

需要 GTK 3 和 WebKitGTK 4.1。Fedora：

```bash
sudo dnf install webkit2gtk4.1 gtk3
```

Ubuntu / Debian：

```bash
sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0
```

优先支持 KDE Plasma 和 GNOME。Linux 的连接页和设置页保持原有界面；进入远控后使用窗口顶部的原生应用栏，下方一行放置「设置 / 回到连接页 / 刷新」按钮，远控页面在工具栏下方占满剩余窗口。X11 会话功能完整；Wayland 会话下基本窗口和远控页面可用，但窗口靠边隐藏、全局老板键等桌面级功能可能受桌面限制。

Linux 版 VR 截图会自动查找 SteamVR，并使用其中的 `libopenvr_api.so`。使用前需要安装并启动 SteamVR，并在头显中打开 VR 应用。

## 使用

1. 在左侧填写 dsh-remote-control 显示的远控地址，例如 `http://192.168.1.20:38765/`。
2. 按需勾选「记住该地址」，点「前往」。
3. 页面载入后，点标题栏的「应用 → 设置」调整麦克风、窗口、VR 截图与安全环境。
4. 设置修改后会自动保存；需要应用到当前页面时，点标题栏的「刷新」。
5. 「应用」菜单里的「置顶窗口」可以让本窗口保持在其他窗口前面。
6. 连接页标题栏的语言菜单可切换中文/English；连接后语言会跟随远控页面，并在「应用 → 回到连接页」中返回连接页。
7. Linux 始终使用窗口顶部的原生应用栏和下方工具栏；连接页、远控页和设置页都在这套工具栏下显示。

打开应用菜单时，当前远控画面会变成模糊背景；关闭菜单后恢复显示。

### 窗口

- 「窗口透明度」最低可调到 5%，避免窗口透明到完全找不到。
- 「老板键」点击输入框后按下一个包含 Ctrl、Alt 或 Shift 的组合键。设置后，在任意窗口按这个组合键都能隐藏或重新显示本窗口。
- 开启「窗口靠边隐藏」并勾选上、左、右中的方向后，把窗口拖到对应屏幕边缘，鼠标离开窗口后它会滑出屏幕外；把鼠标移到屏幕边缘附近会滑回来。
- 靠边隐藏方向可以多选；不选方向时不会隐藏。窗口最大化时不会靠边隐藏。
- 开启「减少动态效果」后，靠边隐藏会直接切换位置，不播放滑动动画；界面过渡和远控页面的切页动画也会关闭。

### 麦克风

选中麦克风后下方会显示实时输入电平。远控页面申请麦克风时会自动使用这个设备，不需要再单独授权。

### VR 截图

开启「替换剪切板为 VR 截图」后，远控页面会把读取剪贴板图片改为读取当前 VR 画面。

- 需要 SteamVR 正在运行，并且头显中已经打开 VR 应用。
- Linux 版会从 SteamVR 安装目录或 `openvrpaths.vrpath` 中查找运行库；也可以把 `libopenvr_api.so` 放在程序旁边。
- 开启「延迟 3 秒后截图」后，等待期间每秒响一声提示，最后一声咔嚓后截图。
- 修改后点标题栏「刷新」使设置作用于当前远控页面。

### 安全环境

如果远控地址是 `http://`，浏览器可能不允许语音输入和读取剪贴板。开启「强制开启安全上下文」并刷新页面后，当前地址会获得需要的安全环境。使用 `https://` 时不需要开启。

### VRChat OSC 展示

在 VRChat 中开启 OSC 后，可以把远控页面的状态显示在游戏聊天框里。

1. 打开「应用 → 设置」，滚动到底部的「VRChat OSC 展示」。
2. 打开开关，并在「显示内容」里选择一项：时间、音乐、系统、大肥鱼，或自定义。
3. 默认发送到本机的 `127.0.0.1:9000`。如果 VRChat 在另一台电脑上，把「发送地址」改成那台电脑的 IP，
   端口与 VRChat 的 OSC 端口保持一致。
4. 时间、音乐、系统和性能等内容会显示成带顶部装饰标题、没有底部横线的小面板，约每 1.5 秒刷新一次；
   音乐进度会跟着播放变化。除性能面板显示四行外，其他面板最多三行文字。单行文字过长时末尾始终显示省略号，
   并在相邻两遍文字之间留出间隔连续滚动。
5. 选择「自定义」后会出现文字框。自定义文字会原样发送，不加标题装饰；最多 4 行、160 个字符，空内容不会发送。
   超过 4 行时文字框和提示会标红，且不会保存。文字框下方会显示可用占位符；输入内容后显示替换预览，
   右上角按钮可以在占位符列表和预览之间切换。长行同样会省略并循环滚动。
6. 同一张设置卡片里可以开启「允许推送快速问答内容到 OSC」。刷新远控页面后，在快速问答的回答中选中文字，
   会出现「推送到 OSC」按钮；推送内容以三行显示，仍有后续文字时末行带省略号，先停留供阅读，再逐字滚动，
   滚动结束后去掉省略号并自动恢复原来的显示内容。推送只使用选中文字本身，换行会合并成一段纯文本，
   不会带上 Markdown 格式。

面板中的时间、天气、音乐、性能和余额来自当前连接的远控页面；自定义文字不依赖远控页面。没有连接远控页面时，
时间等模式会显示等待提示。开关、地址、端口、显示内容和自定义文字的修改会立即生效，不需要刷新远控页面；
快速问答推送开关需要刷新一次远控页面后才能显示选中按钮。

## 已知限制

- VR 截图需要 SteamVR 正在运行，并已找到对应的 OpenVR 运行库；Linux 需要安装 SteamVR。
- VR 截图只截取 SteamVR 当前显示的画面；没有运行中的 VR 画面时无法生成图片。
- 延迟提示音使用系统默认播放设备；静音时不会听到提示，但仍会按时截图。
- 应用菜单打开时远控页面会暂时隐藏，关闭菜单后恢复。
- 老板键需要一个包含 Ctrl、Alt 或 Shift 的组合键；如果组合键已被其他程序占用，会提示注册失败。
- 窗口靠边隐藏仅在窗口靠近所选屏幕边缘时生效，最大化时不会隐藏。Linux Wayland 会话可能不允许程序主动移动窗口。
- 「强制开启安全上下文」仅对 Windows 生效；Linux 请使用 `https://` 地址。
- 远控地址可能包含访问令牌，文件以明文保存在 `Data` 中，请勿把 `Data` 文件夹公开分享。
- VRChat OSC 展示需要 VRChat 已开启 OSC，并且发送地址和端口与 VRChat 的 OSC 设置一致；否则聊天框不会出现面板。
- 聊天框最多显示 144 个字符，过长的歌曲名、型号或地点会被省略。
- 面板只使用当前远控页面已有的数据；远控页面关闭某些页面时，对应信息可能不会更新。
- 当前界面支持简体中文和英文；界面字体（Inter、Noto Sans SC、JetBrains Mono）随软件一起提供，不依赖系统字体。

## 数据与重置

所有设置与数据在程序目录的 `Data` 文件夹。删除 `Data` 后重新启动会恢复出厂设置。
